# Truth Boundary

## Defensible claims

- Independent implementation simulation.
- Original workflow, requirements, governance, rollout and UAT artifacts.
- Executable deterministic routing prototype.
- Twelve passed structured routing tests across Italian, Spanish, English and Brazilian Portuguese.
- Grounded in real public-site operating experience.

## Do not claim

- Client engagement or paid consulting project.
- Production integration, API deployment or live users.
- Eight real sites or forty-two real users; these are scenario assumptions.
- Validated natural-language model accuracy.
- Financial ROI or achieved operational outcomes.

## Interview-safe explanation

I built the implementation package and a lightweight rules prototype, not a production SaaS deployment. I started from multi-site public operations, mapped recurring failure modes, and translated them into requirements, ownership, priority rules, rollout gates, training and measures. I then executed twelve structured UAT scenarios in four languages. The next honest step would be connecting the design to a real platform and piloting it against baseline data.
